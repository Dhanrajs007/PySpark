## 📌 Project Overview

**PySpark Playground** contains practical examples demonstrating how to work with **large-scale distributed data** using PySpark.

The emphasis is on:
- ✅ Clean & readable code
- ✅ Practical transformations
- ✅ Spark SQL analytics
- ✅ Enterprise-style data processing patterns

This is **not just theory** — it’s learning by building 🔥
